# 薬剤師の指導モード（2026-09-27）

## 対象と位置付け

PC薬剤選択プレビューに追加。既存の40薬剤・88用量と骨粗鬆症の7薬剤、計47項目が対象。
「すべて」は現在のアプリの登録薬を意味し、国内の全医薬品・配合剤を網羅するものではない。
成人への服薬指導の補助情報であり、処方提案、用量調節、診断、網羅的な禁忌・相互作用チェックではない。
実薬の製品・剤形・用量・回数、適応、腎機能、既往、他院薬などは薬剤師が別途確認する。

指導データは `pharmacist_guidance.py`、画面は `pharmacist_ui.py`。
47項目の名前・個別URL・製剤別補足を `GUIDES` に明示し、推測によるクラスへの割当てをしない。
カタログの全88用量と骨粗鬆症の全選択肢に対応することをテストする。登録外薬は未登録と表示する。
同一薬の用量違いは説明を重複させず、用法は実薬を照合して別途記入する。

## 根拠資料と実装上の判断

確認日：2026-09-27。PMDAの電子添文・患者向医薬品ガイド、日本糖尿病学会、糖尿病情報センターを使用。
各薬剤の資料リンクを画面・印刷用HTMLにも表示する。参照は代表製品を含むため、実薬のメーカー・剤形で最新資料を再確認する。
全文の代替でも、全注意事項を抽出したデータベースでもない。資料の自動更新機能はなく、改訂時には再確認が必要。

### 糖尿病薬・低血糖

- [糖尿病情報センター：シックデイ](https://dmic.jihs.go.jp/general/about-dm/040/060/06.html)：食事・飲水・症状・血糖を伝えて相談。メトホルミン・SGLT2阻害薬はシックデイの休薬を明記。インスリンは一律に止めない。SU薬は食事量等に合わせた個別指示を確認する。
- [同：低血糖](https://dmic.jihs.go.jp/general/about-dm/040/050/05.html)：低値は無症状でも対応し、意識が清明で飲み込める場合のブドウ糖と再確認を案内。意識障害・嚥下困難時は口から与えず救急要請とする。
- [北里大学メディカルセンター：低血糖の説明書（2025-01-14）](https://www.kitasato-u.ac.jp/kmc-hp/section/medical/naibunpitsu-taisha/albums/abm.php?d=134&f=abm00018903.pdf&n=%E4%BD%8E%E8%A1%80%E7%B3%96%E3%81%AE%E8%AA%AC%E6%98%8E%E6%9B%B82025.1.14%E6%89%BF%E8%AA%8D.pdf)：意識障害時の経口摂取による誤嚥リスクも確認。リンクの実体は同院公開資料。
- [日本糖尿病学会：SGLT2阻害薬の適正使用（2022-07-26）](https://www.fa.kyorin.co.jp/jds/uploads/recommendation_SGLT2.pdf)：脱水、シックデイ、正常血糖でも起こるケトアシドーシス、糖尿病治療での予定手術前3日間の休薬。心不全・CKDの飲水指示を上書きせず、適応・術式に応じ処方医へ確認する。
- [メトグルコ患者向けガイド](https://www.info.pmda.go.jp/downfiles/guide/ph/400093_3962002F2027_1_00G.pdf)：乳酸アシドーシス、脱水、過量飲酒、造影検査・手術の休薬計画、飲み忘れ時の扱い。
- [リベルサス電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/620023_2499014F1021_1_07) 7項：最初の飲食前、水120mL以下、服用後30分の制限、飲み忘れ日は飛ばす。
- [オゼンピック電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/620023_2499418G4027_1_07) 7.2項：次回まで48時間以上かどうかで投与忘れ時の対応を分ける。
- [トルリシティ電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/ResultDataSetPDF/530471_2499416G1029_1_24) および [マンジャロ電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/530471_2499422G1024_1_11) 7.2項：次回まで72時間。オゼンピックと混同しない。
- GLP-1/GIP関連薬の膵炎疑い、イレウス、脱水、麻酔・鎮静前の申告を表示。自己判断による増量を促さない。DPP-4阻害薬には皮膚水疱等も表示。
- [ツイミーグ電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/400093_3969026F1027_1_07)：胃腸症状、メトホルミン併用時の注意、腎機能に応じた用法確認。古い「eGFR45未満は一律非推奨」を転記せず、用量を自動判定しない。メトホルミンの休薬ルールを同一薬のように適用しない。
- SU薬の遷延・再発性低血糖、ピオグリタゾンの心不全・むくみ・体重増加も別の説明にする。

### 降圧薬・脂質治療薬

- 降圧薬でふらついたら安全確保し、可能なら血圧・脈・症状を記録して相談。一律の「収縮期血圧90未満なら全薬休薬」等を実装しない。
- [カルベジロール電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/ResultDataSetPDF/430574_2149032F1021_2_15)：急な中断による悪化、徐脈、低血糖症状のマスク。β遮断薬は特に自己中断を避ける説明。
- [エンレスト電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/ResultDataSetPDF/300242_2190041F1027_1_09) 8.1項：ACE阻害薬との同時使用は禁止、双方向の切替に36時間。ARB重複、腎機能・カリウム、血管性浮腫も確認。
- [ミネブロ電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/ResultDataSetPDF/430574_2149049F1027_1_09)：スピロノラクトンとの併用禁忌。腎機能・カリウムの検査、カリウム補充等の確認を促す。
- CCBのふらつき・浮腫・グレープフルーツ、ARB/ACEの脱水・腎機能・妊娠、利尿薬の脱水・電解質異常をクラス別に表示。ニフェジピンは登録製品のCR錠として粉砕等を避ける説明。
- スタチン・エゼチミブは筋症状、暗色尿、肝障害症状を案内。レパーサは自己注射・保存、レクビオは初回・3か月後・以降6か月の受診予定。
- [ネクセトール電子添文](https://www.pmda.go.jp/PmdaSearch/iyakuDetail/180078_2189022F1023_1_01)：尿酸・痛風、スタチン併用時の筋症状・CK。今回確認した日本の添文にない腱障害のルールを輸入せず、海外資料との混同を避けた。

### 骨粗鬆症薬

- [アレンドロン酸35mg患者向けガイド](https://www.info.pmda.go.jp/downfiles/ph/GUI/181615_3999018F2028_3_02G.pdf)：内服錠の起床時・水・30分横にならない等。アレンドロネートの点滴等へ錠剤の説明を適用しない。
- リセドロネートは日・週・月製剤の取り違えに注意し、実薬を確認する。飲み忘れ時の指示を異なる剤形・間隔に一律転用しない。
- [リクラスト患者向けガイド](https://www.info.pmda.go.jp/downfiles/ph/GUI/100898_3999423A5023_1_00G.pdf)：骨粗鬆症用の年1回点滴、腎機能・脱水・カルシウム。悪性腫瘍用のゾレドロン酸の投与法を使わない。
- [プラリアPMDA情報](https://www.pmda.go.jp/PmdaSearch/rdDetail/iyaku/3999435G1023_1?user=1) と [中止後の多発性椎体骨折の注意喚起](https://www.pmda.go.jp/files/000218063.pdf)：骨粗鬆症での6か月間隔、自己中断せず後続治療を計画、低カルシウムへの注意。
- [イベニティ患者向けガイド](https://www.info.pmda.go.jp/downfiles/guide/ph/112292_3999449G1025_2_00G.pdf)：心血管既往の申告、月1回・12か月まで、次の骨粗鬆症薬、低カルシウム・歯科。モデル上の後続アレンドロネートを現在の実薬として勝手に追加しない。
- [フォルテオ患者向けガイド](https://www.info.pmda.go.jp/downfiles/ph/GUI/530471_2439400G1020_1_17G.pdf)：ふらつき、使用手順等。これは毎日製剤の資料で、テリパラチドの週単位製剤にはその製品の説明が必要と明記。毎日製剤の回数・使用期間を自動入力しない。
- [エビスタ患者向けガイド](https://www.info.pmda.go.jp/downfiles/ph/GUI/530471_3999021F1023_1_01G.pdf)：静脈血栓症の症状、長期不動前の少なくとも3日間の休薬、再開時の歩行状態と医師確認。

## 画面・出力の安全対策

- 試算の薬はボタンで「候補」に取り込むだけ。初期状態は未確認・用法空欄。薬袋・お薬手帳で照合し、実薬の用法を記入する。
- 指導欄は `pharm_` の独立したセッション情報。選択・メモで目標値、薬効、リスク曲線、糖尿病モデルの選択は変わらない。糖尿病なしでも全薬を指導用に選べる。
- 普段の注意／体調不良時／受診の目安／飲み忘れ・注射忘れを選択薬ごとに縦に表示。
- 患者用HTMLは全実薬の用法入力と2つの確認が揃うまで生成しない。選択・用法・メモ・連絡先の変更や変更を戻す操作でも確認を解除する。
- ACE阻害薬＋ARNI、スピロノラクトン＋エサキセレノンの未解決の併用禁忌は出力を止める。他の重複等は確認を促す。これら以外の併用が安全であると判定する機能ではない。
- 通常の休薬相談と、添文等に明記された緊急時の中止・受診を区別する。意識障害・強い胸痛・呼吸困難・片麻痺等では測定や薬局の返答を待たず救急要請。
- すべての入力文字列をHTMLエスケープ。患者氏名等は求めず、指導データを診療記録として永続保存しない。「新しい患者さん・指導欄をクリア」で指導欄だけ消去。
- 実薬の用法入力・医療者確認はレビュー手順であり、アプリの臨床的妥当性や患者への適合性を保証するものではない。

## 検証

全47薬剤の個別出力、登録漏れ、88用量の正確な対応、製剤別の飲み忘れ、未登録薬、重複の扱い、実薬・内容確認、編集時の再確認、HTMLエスケープ、患者切替、禁忌時の出力停止を自動テスト。
PC画面テストではモードと指導薬を変更してもリスク曲線・目標値が変わらないこと、非糖尿病モードでも指導薬が選べることを確認する。
スマホ版や元のPCサービスは変更対象外。

実行結果：`tests/` 全体 **143 passed / 136 subtests passed**。
初回の全体実行では変更していないアクセス集計の並列初期化テストにSQLiteの一時ロックが1件発生（残り142件通過）。同じコマンドで再実行し全件通過。アクセス集計の実装はこの変更には含めていない。
ローカルCondaのreadline読み込み不具合を避けるため、テスト起動時のみ既存の `sys.modules["readline"] = None` を使用。アプリの計算・入力は差し替えていない。
