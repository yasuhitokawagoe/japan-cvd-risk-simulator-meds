# HR相当表示（2026-09-26）

チェックでグラフ・上部指標・7アウトカム比較を切り替える表示機能。
元の計算・絶対リスク・書類の値は変更しない。心肺体力選択時は選択後の曲線から換算。

`H(t) = -log(1 - F(t))`、表示値は `H_target(t) / H_baseline(t)`。
単なる累積リスク比 `F_target/F_baseline` ではない。
比例ハザードが成立すればHRと一致するが、一般には基準ハザードで重み付けした期間平均の比。
本モデルの年齢による効果減衰や禁煙後の変化がある場合、瞬間的HRや臨床試験のCox HRと同一ではない。
競合リスク等を含むモデルでのこの換算は、そのモデルの累積曲線に対応するHR相当であり、原因別HRを意味しない。

基準は治療開始モードでは現在のリスク因子、継続モードでは服薬継続。基準は1。
全薬中止は継続に対する比となるので、利益のある薬の中止では1を超え得る。
「ハザードの変化」は `(1-ratio)×100` であり、絶対リスク差ではない。

帯は `H_target_lower/H_baseline_upper` から `H_target_upper/H_baseline_lower` までの参考幅。
元の95%幅を端点同士で換算した範囲で、共同分布・相関を推定したHRの95%CIではないことを明記する。
開始時の0/0、基準リスク0%、100%への飽和、非有限値では欠測扱い（指標は算出不可）とし、偽の1を補完しない。
基準の1は定義上の参照線である。確率配列を上書きしない。

HRモードでは絶対リスク差ptの治療別内訳を非表示にする。骨の参考パネルは独立した機能で変更しない。
書類は絶対リスクのまま。心肺体力の探索的上乗せを書類に含めない既存仕様も維持。
テストは `tests/test_risk_display.py` と `tests/test_risk_display_ui.py`。
