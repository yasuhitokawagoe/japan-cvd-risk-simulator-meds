## 解釈と制限

- 原著の有酸素SBPには不整合がある。Figure 3は-1.24、抄録の範囲下端も-1.24だが、本文Blood pressure節は-1.14と記載。アプリは図3と整合する-1.24を維持し、本文の数値で上書きしない。
- -4.15 mmHgは筋力トレーニング単独の推定値。これを有酸素・複合・HIITへ一律に流用しない。したがって有酸素の血圧効果が小さすぎるという一律の説明は正確ではない。
- 運動種別間の血圧効果の差は統計学的に有意ではない。数値の大小を種類間の優越性が証明されたものとして扱わない。
- 対象は2型糖尿病成人。確立した心血管・肺・神経・腫瘍疾患や不安定な慢性疾患を持つ患者は原著の適格基準で除外されており、そうした患者への適用は外挿となる。
- UIの週150–210分などは運動メニューの目安。採用値は各種類全体の平均で、その時間・強度だけに限定した推定値ではない。個人の達成値を保証しない。
- 血圧・LDL・HbA1cの変化を既存リスクエンジンへ入力する。短期の危険因子改善から長期リスクへの変換はモデル上の外挿であり、運動RCTが直接その長期予防率を証明したものではない。
- チェックがオフの通常推計では心肺体力・筋力・体重や観察研究の死亡率低下を別途加算しない。心肺体力については下記のオプトイン式探索的シナリオを選択できる。
- 既存の糖尿病適用制限、目標リセット、食事との組合せ、最低値ガードは維持。

## 心肺体力の探索的上乗せ（初期状態オフ）

ユーザーの明示的な選択時だけ、全死亡の介入後曲線を心肺体力込みの推定に置換する。
旧介入後曲線は重ねず、現在のリスク曲線と選択中の介入後曲線を通常と同じ線・色・年齢による薄色化で表示する。
介入後の幅は下記の95%推定幅に置換。上部の全死亡・ARR、7アウトカム比較の全死亡・ARR、治療内訳も同じ推定へ連動する。
治療内訳には通常の運動効果の後に心肺体力の追加分を一度だけ追加する。
書類の数値は通常推計のままに保ち、書類作成画面で除外を明記する。
心筋梗塞、脳卒中、認知症、糖尿病合併症、骨折には適用しない。
服薬継続/中止比較モードや運動未選択時には適用しない。

### 入力と計算

- 運動RCT解析のVO₂peak平均改善（本文Physical fitness節）：有酸素+2.77、複合+2.68、HIIT+4.19 mL/kg/min。1 MET = 3.5 mL/kg/min。
- 全死亡との関連：Laukkanen JA, Isiozor NM, Kunutsor SK. Mayo Clin Proc. 2022;97:1054–1073. DOI https://doi.org/10.1016/j.mayocp.2022.02.029 、PubMed https://pubmed.ncbi.nlm.nih.gov/35562197/ 。37コホート・2,258,029人。多変量調整後のRR 0.89/MET（95%CI 0.86–0.92）。
- 倍率 `m = 0.89 ** (VO₂peak改善 / 3.5)`。
- 通常介入後の累積死亡確率を `p` とし、探索的確率を `1 - (1 - p) ** m` とする。これはRRを比例ハザード倍率として近似する追加のモデル仮定であり、原著が検証した計算法ではない。
- 改善達成後の状態を予測開始時から全期間維持すると仮定する。改善までの時間、中断・減衰は未モデル化。経年でMET改善や倍率をさらに累積しない。

### 強い制約

心肺体力の高低と死亡の関連は、運動で同じ量を改善させた場合の因果的な治療効果ではない。
一般集団の関連を糖尿病モデルへ移植し、短期の運動試験の改善を長期に外挿している。
多変量調整済みでも、現在の血圧・LDL・HbA1c等の効果との重複や残余交絡は除去できない。
したがって、この乗算は過大評価し得る探索的シナリオであり、検証済みの独立した追加予防率とは表示しない。
元の通常曲線の95%CIや観察研究のCIだけを流用して、合成シナリオの95%CIとは表示しない。
画面でこれらを警告し、曲線・数値に「心肺体力込み・推定」のラベルを付ける。

### 95%推定幅（近似、検証済みの信頼区間ではない）

原著本文のVO₂peak改善95%CI：有酸素1.98–3.56、複合1.66–3.70、HIIT2.59–5.79 mL/kg/min。
RRの95%CIは0.86–0.92/MET。両者と元モデルの幅を独立と仮定して合成する。

1. `M = VO₂改善 / 3.5`、`b = log(0.89)`。
2. `SE_M = (VO₂上限 - 下限) / (3.92 × 3.5)`、`SE_b = (log(0.92) - log(0.86)) / 3.92`。
3. デルタ法による `Var(log m) ≈ b² SE_M² + M² SE_b²`（共分散を0と置く）。
4. 元のリスク・下限・上限をそれぞれ累積ハザード `H = -log(1-p)` へ変換。`log H`の中心から各端までの距離/1.96を左右別の元SEと近似する。
5. `log H + log m ± 1.96 × sqrt(SE_base_side² + Var(log m))` を計算し、`1-exp(-H)`で確率へ戻す。
6. 0%・100%の端点は対数変換せず保つ。入力境界や配列長が不正なら拒否する。

元エンジンの幅には、基礎発症率に設定した割合の上下動などのモデル上の仮定も含まれる。
そのためこの合成幅は名目的な95%相当のモデル不確実性幅であり、被覆確率95%が実証された区間ではない。
研究間の異質性、個人差、共分散、二重計上、未調整交絡、長期維持の不確実性は十分には表現しない。
点推定値だけに倍率を掛けて古い帯を残すことや、RRのCIだけで帯を作ることはしない。

同テストで上下限の順序・元幅の合成による幅の拡大も確認。
