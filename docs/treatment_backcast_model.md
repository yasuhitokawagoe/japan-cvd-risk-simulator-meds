# これまでの治療で得られた利益（反実仮想モデル）

## 比較する2つの経路

1. **薬を飲まなかった経路**: 現在の検査値から薬剤カタログの平均効果を逆算した危険因子が続いたと仮定。
2. **薬を飲み続けた現在の経路**: 服薬年数を治療期間で按分し、期間平均の危険因子を算出。

治療開始年齢（現在年齢 - 治療年数）から現在まで、既存の累積発症アルゴリズムへ2経路を入力する。矢印を「今後の介入」から「過去に介入しなかった場合との比較」へ逆転させる設計である。

## 薬効の逆算

- 血圧・HbA1c: 薬剤効果は加算なので、現在値から負の効果量を差し引いて無治療値を復元する。
- LDL: 薬剤効果は割合の掛け算なので、現在値を残存率の積で割って無治療値を復元する。
- 服薬年数が治療期間より短い場合は、効果を `服薬年数 / 治療期間` で按分する。

## 表示

- 無治療推定値と現在値
- 全死亡・心筋梗塞・脳卒中の累積リスク差
- 100人あたり回避できたと推定されるイベント数
- ARRが正なら NNT相当値（1件回避するために必要な治療人数）

## 限界

- 実測した治療開始前値がある場合は、逆算値より実測値を優先すべき。
- 服薬遵守、用量変更、途中中断、生活習慣の変化は期間平均で近似する。
- 「薬を飲まなかった場合」は観測できない反実仮想であり、個人の実績を断定するものではない。
