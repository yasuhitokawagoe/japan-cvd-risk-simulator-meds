# 保険負担・高額療養費の自動試算

確認日: 2026-09-26。対象制度期間: **2026年8月～2027年7月**。

## 対象と表示

薬剤選択欄の薬剤料について、一人・同じ処方元の外来とその調剤薬局分を対象に試算する。
保険証等の自己負担割合と保険者の認定所得区分を選ぶと、月額上限、多数回該当、年間上限を自動計算する。
年齢・所得・保険者は期間中同じとする。所得区分未選択の場合は適用前費用だけを表示し、区分を推定しない。
保険なしは10割で給付なし。対象年齢は既存アプリの20～95歳。

69歳以下は3割、70～74歳は2割または3割、75歳以上は1・2・3割から選択。
現役並み所得は3割。75歳以上の2割は一般区分のみ。
国保と被用者保険で所得判定方法が異なるため、年収による自動認定はせず、保険者の認定区分をユーザーが選ぶ。
障害認定で65歳から後期高齢者医療へ移行した場合などの例外は対象外。

| イ / 現役Ⅱ | 179,100 + max(0,総医療費−597,000)×1% | 93,000 | 1,110,000 |
| ウ / 現役Ⅰ | 85,800 + max(0,総医療費−286,000)×1% | 44,400 | 530,000 |
| エ | 61,500 | 44,400 | 530,000 |
| エ・標準報酬15万円以下等の確認済み対象者 | 61,500 | 44,400 | 410,000 |
| オ・70歳未満非課税 | 36,900 | 24,600 | 290,000 |
| 70歳以上外来・一般 | 22,000 | 外来個人上限のみではカウントしない | 216,000 |
| 70歳以上外来・低所得Ⅱ | 11,000 | 同上 | 96,000 |
| 70歳以上外来・低所得Ⅰ | 8,000 | 同上 | 外来年間上限なし |

元の自己負担額を超える上限は適用しない。給付が実際に発生する月を該当月として記録し、直近11か月に3月以上ある場合、当月を4回目以降として多数回限度額を適用する。
開始前11か月の履歴を月別に入力でき、時間経過で該当月が範囲外になる。未入力は履歴なし。
70歳以上の一般・低所得の外来個人上限のみで生じた給付は多数回に数えない。
年間上限は8月～翌7月の月額適用後負担を集計して別途還付とする。70歳未満は自己負担21,000円未満の月を年間合算にも含めない。
画面の「年間自己負担」は還付後の額。「月平均」は年額÷12であり毎月の窓口負担額ではない。
実際の申請・給付処理は行わない。

## 薬剤費の月別割付

- 固定の算定年は2026-08-01～2027-07-31。将来の2027年8月改定を混在させない。
- 毎日服用薬は既存年間価格を365日で割り、各月の日数に按分。毎月処方の消費量概算。
- 週1回・隔週注射は8月1日から7日・14日ごとの投与日に計上。この暦年では初日を含め53回・27回となる。既存カタログの52週換算の年額から1回単価を取り出す。
- レパーサは厚労省リストの24,302円/140mgペンに修正。カタログは26回＝631,852円、今回の暦日モデルでは27回＝656,154円。内訳に回数を表示。
- レクビオは394,758円/筒。初年度は8・11・5月の3回、維持期は8・2月の2回。年額を12等分せず、投与月に全額を置いて月上限を計算する。
- ビクトーザは既存の18mgキットの消費量按分。端数キットの購入単位や導入時の漸増を再現しない。
- 診察・検査・調剤・注射手技・針代、別の骨粗鬆症欄の薬剤、他の医療費、世帯合算、自治体助成、健保独自の付加給付等は含めない。
- 自己注射の複数月処方では実際の支払月と投与月が異なる。試算は投与月に薬剤費を計上する前提を明示し、実請求額を保証しない。
- 内部計算では端数を保持し、表示時に円単位四捨五入。実際のレセプト端数処理とわずかな差が生じ得る。
